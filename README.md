# ONE4ALL meme artwork

Artwork for the ONE4ALL meme collection and PFP maker at https://o4asol.com. This repository contains public assets and their provenance, without website runtime code.

The packs are pinned by commit for stable, unmodified image delivery. Original image files and SHA-256 checksums are retained; no website code, account data, or service configuration is included.

## September 10 community stickers

The optional laptop sticker collection now includes BONK, POPCAT, MEW, PONKE, WEN, and MOODENG. Source files are retained unchanged under `pfp/stickers/`; `community-stickers-manifest.json` records their hashes and `pfp/stickers/community-sources.json` records the project-site origins.

These are third-party community decorations, not ONE4ALL-owned characters or partnership announcements. Their names and artwork remain with their respective owners. Existing immutable meme and PFP references are unchanged.

Create a PFP at [o4asol.com/?view=create](https://o4asol.com/?view=create). Read the [project mission and current release](https://github.com/o4a-sol/ONE4ALL/blob/main/NOW.md).
